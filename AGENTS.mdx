## What to read

- [llms.txt](https://docs.dazie.io/llms.txt) indexes every page, and [llms-full.txt](https://docs.dazie.io/llms-full.txt) holds the whole corpus in one file.
- Every page has a Markdown twin: append `.md` to its URL.

## What to call

- Docs MCP server: `https://docs.dazie.io/mcp` searches and reads these docs, no authentication.
- dazie MCP server: `https://api.dazie.io/mcp` reads and writes the signed-in user's journal, to-dos and memories.
- REST API: `https://api.dazie.io/v1`, spec at [api.dazie.io/v1/openapi.json](https://api.dazie.io/v1/openapi.json).

Everything that touches user data needs the user's OAuth token. See [Authentication](/auth).

## What is not here

Agents can't create accounts, delete data, place calls or change a user's schedule. People sign up at [app.dazie.io](https://app.dazie.io/).
