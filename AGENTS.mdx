## What to read

- [llms.txt](https://docs.dazie.io/llms.txt) indexes every page, and [llms-full.txt](https://docs.dazie.io/llms-full.txt) holds the whole corpus in one file.
- Every page has a Markdown twin: append `.md` to its URL.

## What to call

- MCP server: `https://docs.dazie.io/mcp` searches and reads these docs. It needs no authentication.
- Agent skill: [/.well-known/agent-skills/index.json](https://docs.dazie.io/.well-known/agent-skills/index.json).

## What is not here

dazie has no public API for user data, and agents cannot register or act on a user's behalf. People create accounts at [app.dazie.io](https://app.dazie.io/).
