The `dazie` npm package is a typed client for the [dazie API](/api-reference/introduction). It has no dependencies and runs anywhere with `fetch`: Node.js 18+, Bun, Deno and browsers.

```sh
npm install dazie
```

## Authenticate

Every request acts as one dazie user. For your own account, sign in once with the CLI and pass the saved token, or set `DAZIE_TOKEN`:

```sh
npx dazie login
```

```ts
import { Dazie } from 'dazie';

const dazie = new Dazie(); // reads DAZIE_TOKEN
const me = await dazie.me();
console.log(me.email, me.onboarded);
```

For an app that acts for other people, run the OAuth 2.1 flow described in [Authentication](/auth) and pass each user's access token: `new Dazie({ token })`. `token` can also be a function that returns a fresh token, which the client calls before every request.

## Journal

```ts
const { total, entries } = await dazie.journal.list({ since: '2026-10-01', limit: 20 });
const matches = await dazie.journal.list({ query: 'sister' });
const entry = await dazie.journal.get(entries[0].id, { includeTranscript: true });

await dazie.journal.create({
  title: 'Sunday walk',
  content: 'Long walk, felt lighter after.',
  mood: 'calm',
  tags: ['walk'],
});
```

Write entries in the user's own words.

## To-dos, memories and schedules

```ts
const open = await dazie.todos.list({ status: 'open' });
const todo = await dazie.todos.add({ text: 'Call Sam back', dueDate: '2026-11-02' });
await dazie.todos.update(todo.id, { status: 'done' });

const goals = await dazie.memories.list({ type: 'goals' });
await dazie.memories.add({ type: 'relationships', content: 'Sam is my sister' });

const schedules = await dazie.schedules.list(); // daysOfWeek: 0 = Sunday
```

## Errors

Every failure throws a `DazieError` with a `code`, a `message` and, for HTTP errors, the `status`.

```ts
import { Dazie, DazieError } from 'dazie';

try {
  await dazie.journal.create({ title: 'First entry', content: 'Hello' });
} catch (error) {
  if (error instanceof DazieError && error.code === 'onboarding_required') {
    console.log('Finish onboarding at https://app.dazie.io first');
  } else throw error;
}
```

| Code | Meaning |
|---|---|
| `unauthorized` | No token, or it expired. Sign in again. |
| `invalid_request` | An input failed validation. The message names the field. |
| `not_found` | The record doesn't exist or belongs to someone else. |
| `onboarding_required` | The user hasn't finished onboarding at app.dazie.io. |
| `network_error` | The API couldn't be reached. |
| `internal_error` | Something failed on dazie's side. |

## Options

| Option | Default |
|---|---|
| `token` | `process.env.DAZIE_TOKEN` |
| `baseUrl` | `process.env.DAZIE_API_URL`, then `https://api.dazie.io` |
| `fetch` | the global `fetch` |
