## How a companion supports a habit

Dazie is a voice-first AI journaling companion. You create a companion during onboarding, then talk with it by text in the web app. The companion asks follow-up questions and remembers what you share, so each conversation can pick up where the last one ended.

Dazie is a reflection tool, not therapy.
